## Overview

Microsoft Teams is a popular team chat app that allows nonprofit team members to connect and collaborate from anywhere. It is ideal if you work mostly with Microsoft software, as it fits nicely alongside document management and file-sharing tools.

## Key Features

- Real-time collaboration
- File sharing
- Tasks
- Live polls
- Meeting transcripts

## Pricing

Microsoft Teams' pricing starts at $4 per month per user. It is also included as part of a Microsoft 365 subscription, starting at $6 per user per month.

## Integrations

Microsoft Teams pairs well with the rest of the Microsoft 365 suite, and can also be paired with tools like HubSpot, Google Sheets, and Jotform via Zapier.

## Use Cases

Text conversation channels, audio calls, video calls, virtual meetings, and team collaboration for nonprofit staff.
