## Overview

Charitable is a WordPress donation plugin developed by Studio 164a designed to help non-profits maximize their online fundraising efforts. It provides unlimited campaigns, secure payment gateways, and zero transaction fees, positioning it as a solution for organizations of all sizes.

## Features

- Customizable Forms
- Matching Gifts
- Fundraising Campaigns
- Recurring Donations
- Pledge Management
- Software Integration
- Donor Segmentation
- Donation Tracking
- Unlimited Campaigns
- Secure Payment Gateways
- Zero Transaction Fees
