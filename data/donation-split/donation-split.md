## Overview

Donation Split is a tool that helps nonprofits and educational institutions manage donations more effectively. Built to work with Salesforce, it lets organizations allocate donations according to each donor's preferences, making it easy to split funds across different programs or years.

## Features

- Fundraising Campaigns
- Grant Management
- Multi Currency
- Recurring Donations
- Event Management
- Reporting And Analytics
- Access Controls
- Salesforce Integration
- Donor Preference Allocation
