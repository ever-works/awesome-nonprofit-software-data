## Overview

Jitsi is a set of open-source projects that allows teams to easily build and deploy secure videoconferencing solutions. It provides encrypted video conferencing, screen sharing, meeting recording, and streaming capabilities.

## Key Features

- Secure video conferencing
- Screen sharing
- Meeting recording
- Live streaming
- End-to-end encryption
- Open source (self-hosted)
