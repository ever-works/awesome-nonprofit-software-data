## Overview

WordPress is the world's most famous open-source content management system (CMS). It provides website creation, content publishing, themes, and plugin extensibility for nonprofit organizations building websites, blogs, and donation portals.

## Key Features

- Content creation and publishing
- Themes and plugins
- Media management
- User management
- Open source (self-hosted)
