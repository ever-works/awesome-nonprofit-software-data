## Overview

Joomla! is a free and open-source content management system (CMS) for publishing web content. It provides content management, user management, templates, and extension extensibility for nonprofit websites.

## Key Features

- Content management
- User management
- Templates and extensions
- Multilingual support
- Open source (self-hosted)
