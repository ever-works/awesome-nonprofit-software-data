## Overview

GeoNode is a free and open-source geospatial content management system written in Django. It provides geospatial data sharing, mapping, catalog, and visualization capabilities for organizations working with geographic data.

## Key Features

- Geospatial data catalog
- Map creation and visualization
- Data sharing and publishing
- Django-based web application
- Open source (self-hosted)
