## Overview

KoBoToolbox is an open-source data collection toolset designed for humanitarian and development contexts. It enables organizations to collect, manage, and visualize data in the field, particularly useful for NGOs and nonprofits.

## Key Features

- Mobile and web-based data collection
- Offline data collection capability
- Data visualization and export
- Survey design and deployment
- Open source (self-hosted)
