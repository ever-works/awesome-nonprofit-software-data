## Overview

Scribus is a fully featured, free and open-source desktop publishing tool. It provides professional page layout, typesetting, and print-ready document creation for nonprofit publications and materials.

## Key Features

- Professional page layout
- Typesetting and typography
- CMYK color support
- PDF export
- Open source (desktop)
