## Overview

OpenProject is an open-source project management software written in Ruby. It provides project planning, task management, timelines, Gantt charts, and team collaboration features suitable for nonprofit and NGO teams.

## Key Features

- Project planning and scheduling
- Task management
- Gantt charts and timelines
- Team collaboration
- Time tracking
- Open source (self-hosted and cloud options)
