## Overview

Open Data Kit (ODK) is a free and open-source set of tools for collecting, managing, and using data in resource-constrained environments. It is designed for field-based organizations including nonprofits and NGOs.

## Key Features

- Mobile data collection forms
- Data aggregation and management
- Offline data collection
- GPS and multimedia capture
- Open source (self-hosted)
