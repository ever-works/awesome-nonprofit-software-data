## Overview

Elgg is a well-documented, free and open-source social intranet software. It provides social networking, content sharing, and collaboration tools for organizations and communities.

## Key Features

- Social networking
- Content sharing
- User profiles and groups
- Activity streams
- Open source (self-hosted)
