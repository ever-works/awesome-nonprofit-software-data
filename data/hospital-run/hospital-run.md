## Overview

HospitalRun is free and open-source healthcare/hospital management software. It provides hospital information system functionality for healthcare facilities in developing regions, with offline capability and sync features.

## Key Features

- Hospital information system
- Patient management
- Offline capability with sync
- Inventory management
- Open source (self-hosted)
