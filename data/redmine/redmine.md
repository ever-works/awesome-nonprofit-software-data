## Overview

Redmine is a fully-featured, free and open-source project management software written in Ruby on Rails. It provides flexible project tracking, issue management, Gantt charts, and calendar functionality for teams.

## Key Features

- Multiple projects and subprojects
- Issue tracking and workflow customization
- Gantt charts and calendar
- Time tracking
- Role-based access control
- Open source (self-hosted)
