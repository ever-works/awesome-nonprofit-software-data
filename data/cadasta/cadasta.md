## Overview

Cadasta is an open and flexible suite of mobile and web-based tools designed to help users collect, manage, and store land and resource rights data. It supports land tenure documentation for communities and organizations.

## Key Features

- Mobile data collection for land rights
- Web-based data management
- Land tenure documentation
- Geospatial data capture
- Open source
