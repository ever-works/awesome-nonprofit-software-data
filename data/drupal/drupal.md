## Overview

Drupal is an open-source security-first content management system (CMS). It provides flexible content management, granular user permissions, and module extensibility for nonprofit websites and digital platforms.

## Key Features

- Content management
- Granular user roles and permissions
- Module extensibility
- Multilingual support
- Open source (self-hosted)
